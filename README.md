## Sección de reflexión

* ¿Qué aspectos del proceso consideré más accesibles o fluidos para mí?
Los condicionales, ya que es un tema que ya había entendido e implementado correctamente en Python. Ver que son similares en JavaScript me facilitó ponerlos en práctica.

* ¿Qué elementos representaron un mayor nivel de desafío y por qué?
Las diferentes formas de declarar una función, ya que en Python solo utilizaba la palabra clave def. En cambio, en JavaScript existen varias formas, como con la palabra reservada function o con las funciones flecha (=>). Eso me generó algo de confusión al principio.  

* ¿Qué estrategias implementé para superar los obstáculos que se presentaron durante el proceso?
Practiqué con los distintos métodos para declarar funciones. Al realizar varios ejercicios, pude comprender cómo se usan y cuál es la forma correcta de escribirlas.

* ¿Qué conceptos o procedimientos aún no comprendo completamente y en qué aspectos específicos necesitaría orientación adicional?
Aún no comprendo del todo los diferentes métodos que existen para los arrays, así como la diferencia entre for...in y for...of. Aunque he practicado un poco, necesitaría más orientación especialmente sobre cuándo y cómo usar correctamente los distintos tipos de bucles for, ya que cada uno tiene una función distinta.
